### T5
- P1 reliability — SolarSystem.tsx:2954–2994 wraps all scene content, controls, stars and orbits in one Suspense boundary. Any pending external useTexture hides the whole scene; rejected loads propagate out of Canvas without a local error boundary or per-body fallback. Earth requests all five maps even with clouds disabled (1778–1784); Saturn rings add another dependency (1629). This is a concrete all-or-nothing failure mode, not evidence that a particular URL currently fails.
- P2 precision — Physical overview uses near=1e-7 and far=1800 (2744–2750,2956–2960). Node/Three projection math showed distances 10,100,425,1000 all quantize to the same maximum 24-bit depth bin, with float32 projected z/w=1. This destroys depth separation; it is not proof that everything is hard-clipped. Use distance-aware overview clipping rather than the microscopic close-up near plane everywhere. Existing closeupDistances uses radius-relative near and is appropriate locally.
- P2 discovery/labels — Sun/planet labels require selection or hover (1385,1561); transparent physical hit spheres remain tiny in screen space (1345,1445,1532). Sun has no catalogue button (3235–3263). Luna always has a full-size Html label (1929), almost coincident with Earth's at overview distance; body labels are noninteractive CSS. Drei Html without distanceFactor stays full CSS size, so missing ALL labels is not explained by physical radius alone.
- P2 picking — The 8-radius planet proxy at 1520–1534 stops propagation ahead of visible inner moons when viewed from outside it. A pure Three Raycaster aimed at Io from 20 Jupiter radii returned the opacity-zero Jupiter proxy first (distance 0.05223), then unobscured Io (0.07995). Phobos/Deimos/Enceladus are similarly within their parent proxies. Prefer real visible geometry over fallback hit targets; opacity=0 does not disable raycasting.
- P2 framing — Fixed overview positions at 2720/2957 do not fit the entire system.
